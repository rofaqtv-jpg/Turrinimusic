الإعداد المجاني (مرة واحدة فقط)

  1. أنشئ حساباً مجانياً في github.com ثم أنشئ مستودعاً جديداً Public باسم مثل turrinimusic
  2. ارفع 4 ملفات إلى المستودع بالسحب والإفلات: index.html + admin.html + data-loader.js + data.json
  3. فعّل الاستضافة المجانية: Settings → Pages → Source: main branch → Save وسيصبح موقعك على USERNAME.github.io/turrinimusic
  4. أنشئ رمز وصول مجاني: Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate واختر صلاحية public_repo فقط
  5. الصق اسم المستخدم والمستودع والرمز في تبويب الإعدادات ثم اضغط اتصال — بعدها أضف/عدّل/احذف واضغط نشر
